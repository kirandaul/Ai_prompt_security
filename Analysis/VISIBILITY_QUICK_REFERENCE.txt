📝 COMPONENT 3: DEBUG LOGGING SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

File: extension/js/debug_logger.js
Size: ~8 KB
Instance: window.debugLogger (global)

Three Log Entry Types:

1. SCAN LOG (complete decision)
   {
     timestamp, scanId, action, severity, totalFindings,
     findings: [{detector, category, severity, confidence, evidence}],
     decision: {allowSend, reason, factors}
   }

2. DETECTOR LOG (per-detector execution)
   {
     timestamp, scanId, detector, matched,
     validation: {isValid, isReal, type, reason, details},
     decision: {status, severity, reason, confidence}
   }

3. VALIDATION LOG (validation checks)
   {
     timestamp, scanId, validationType,
     result: {passed, score, reason, details}
   }

API Methods:

  logScan(scanId, prompt, result)
    → Log complete scan with findings
  
  logDetectorResult(scanId, detector, matched, validation, decision)
    → Log individual detector execution
  
  logValidation(scanId, type, value, result)
    → Log validation check (Luhn, domain, entropy, etc.)
  
  getStats()
    → Get aggregated statistics
    → Returns: {totalScans, totalDetections, detectors, actions, severities}
  
  exportLogs(filter)
    → Export as JSON for analysis
  
  exportLogsCSV()
    → Export as CSV for spreadsheet
  
  getLogs(limit)
    → Get recent logs (default 50)
  
  clearLogs()
    → Reset storage
  
  setEnabled(true/false)
    → Turn logging on/off

Usage:

  // Log a scan
  debugLogger.logScan(scanId, prompt, scanResult);

  // Get statistics
  const stats = debugLogger.getStats();
  console.log(stats);

  // Export data
  const json = debugLogger.exportLogs();
  const csv = debugLogger.exportLogsCSV();
