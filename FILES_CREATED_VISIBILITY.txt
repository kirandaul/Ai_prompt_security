      Size: ~8 KB
      Type: JavaScript class
      Purpose: Complete audit trail for all detection decisions
      
      Class: DetectionDebugLogger
      
      Methods:
      ├── Constructor & initialization
      ├── logScan(scanId, prompt, result) — Log complete scan
      ├── logDetectorResult(...) — Log per-detector execution
      ├── logValidation(...) — Log validation checks
      ├── extractDecisionReason() — Human-readable summary
      ├── extractDecisionFactors() — Decision reasoning breakdown
      ├── getDetectorReasoning() — Detector-specific logic
      ├── exportLogs() — Export as JSON
      ├── exportLogsCSV() — Export as CSV
      ├── getLogs() — Retrieve recent logs
      ├── getStats() — Aggregate statistics
      ├── clearLogs() — Reset storage
      ├── setEnabled() — Toggle logging on/off
      ├── openDebugPanel() — Launch debug UI
      ├── loadSettings() — Load from Chrome storage
      ├── isDevelopment() — Check if dev mode
      └── addLog() — Internal append & persist
      
      Log Entry Types:
      
      SCAN:
      {
        timestamp, scanId, promptLength, action, severity,
        totalFindings, findings: [{detector, category, severity, 
        confidence, evidence}], decision: {allowSend, reason, factors}
      }
      
      DETECTOR:
      {
        timestamp, scanId, type, detector, matched, 
        validation: {isValid, isReal, type, reason, details},
        decision: {status, severity, reason, confidence}
      }
      
      VALIDATION:
      {
        timestamp, scanId, type, validationType,
        result: {passed, score, reason, details}
      }
      
      Features:
      ├── Automatic timestamping
      ├── Scan ID tracking
      ├── Circular buffer (max 500 logs)
      ├── Chrome storage persistence
      ├── Development console logging
      ├── Statistics aggregation
      ├── CSV and JSON export
      ├── Enable/disable control
      └── Debug panel launcher

   Global Instance: window.debugLogger
