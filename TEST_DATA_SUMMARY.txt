TEST CASE SCHEMA
================================================================================

Each test case is a JSON object with:

{
  "id": 1,
  "name": "OpenAI API Key",
  "category": "SECRET|PII|ATTACK|COMPLIANCE|INFRA|SAFE",
  "detector": "API_KEY_DETECTOR",
  "severity": 0-100 (0=safe, 100=critical),
  "expectedDetection": true|false (should detector trigger?),
  "difficulty": "easy|medium|hard",
  "tags": ["secret", "openai_key", "active"],
  "source": "developer|devops|finance|hr|healthcare|security",
  "format": "text|json|yaml|code|log",
  "prompt": "actual test prompt text"
}

================================================================================
USAGE EXAMPLES
================================================================================

1. LOAD IN PYTHON
   ───────────────
   import json
   with open('test-data/prompts.json', 'r') as f:
       data = json.load(f)
   print(f"Loaded {data['total_cases']} test cases")

2. TEST SINGLE CASE VIA API
   ────────────────────────
   curl -X POST http://127.0.0.1:3000/api/tester/scan \
     -H "Content-Type: application/json" \
     -d '{"prompt":"sk-proj-abc...","expected_detector":"API_KEY_DETECTOR"}'

3. FILTER BY CATEGORY
   ───────────────────
   secret_cases = [c for c in data['cases'] if c['category'] == 'SECRET']

4. FILTER BY DETECTOR
   ──────────────────
   api_key_cases = [c for c in data['cases'] if c['detector'] == 'API_KEY_DETECTOR']

5. FILTER BY DIFFICULTY
   ────────────────────
   hard_cases = [c for c in data['cases'] if c['difficulty'] == 'hard']

6. NEGATIVE TESTS (should NOT trigger)
   ──────────────────────────────────
   safe_cases = [c for c in data['cases'] if c['expectedDetection'] == False]
